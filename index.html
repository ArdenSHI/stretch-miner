你的摄像头画面就在画布底部正中那格里（镜像，像照镜子），手臂从格子上方伸出去。
不用手的控制：身体（或头）往左挪一点，手臂就朝左上方伸；一直偏着就一直长；挪回画面中间就极速收回。 抓到钻石 / 金块 / 钱袋 +1 分，碰到炸弹立刻收回扣一条命，共三条命；宝物全部抓完即结束。
也可以切「伸手臂控制」：向斜上方举一只手并保持住。没有摄像头或被拒绝授权时会自动切到鼠标模式： 按住鼠标朝一个方向拖，松手即收回。摄像头必须在 localhost 或 HTTPS 下使用； 画面只在本地处理，不上传、不保存。
库和模型都已放在本地 vendor/，不需要联网。用 python3 serve.py 启动最稳。 没反应时看什么：画布下方那行诊断。摄像头 ✓ + 模型 ✓ + 检测到人 ✓ 三个都亮了才算通； 哪个是 ✗ 就告诉我哪一项。三个都亮但还是伸不出，就拉「灵敏度」滑块，或者坐正后点「以现在的位置为中间」再挪。 画面里那两条红色小刻度就是"伸出手臂"需要的偏移量，黄线要越过它。

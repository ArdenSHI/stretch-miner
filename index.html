Stretch Miner · 帮老奶奶找首饰

老眼昏花的奶奶把眼镜、项链、耳环掉落在一张乱糟糟的桌面上 —— 你的身体往左/右挪一点，她的手就朝那边伸过去。别碰虫子和裸露的插头。

找到 0 还没找到 0 还剩几次机会 点「开始」授权摄像头
数字越大越灵敏：手伸不出去就往右拉，老是自己乱伸就往左拉
诊断：等待开始…

摄像头那格就是奶奶的脸（镜像，像照镜子），她披着针织披肩，手从画面上沿伸出去。
怎么玩：身体（或头）往左挪一点，手就朝左上方伸；一直偏着就一直长；挪回画面中间就极速收回。 找到眼镜 / 项链 / 耳环 / 戒指 / 胸针 / 发夹 +1 分；碰到虫子或裸露的插头会整个窗口一震，并少一次机会，一共三次； 桌上的首饰全部找完即结束，最后一帧会留在结算画面里。
也可以切「伸手臂控制」：向斜上方举一只手并保持住。没有摄像头或被拒绝授权时会自动切到鼠标模式： 按住鼠标朝首饰的方向拖，松手即收回。摄像头必须在 localhost 或 HTTPS 下使用； 画面只在本地处理，不上传、不保存。
库和模型都已放在本地 vendor/，不需要联网。用 python3 serve.py 启动最稳。 没反应时看什么：画布下方那行诊断。摄像头 ✓ + 模型 ✓ + 检测到人 ✓ 三个都亮了才算通； 哪个是 ✗ 就告诉我哪一项。三个都亮还是伸不出，就拉「灵敏度」滑块，或者坐正后点「以现在的位置为中间」再挪。
